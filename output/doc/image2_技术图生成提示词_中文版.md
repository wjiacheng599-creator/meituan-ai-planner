# Image 2 技术图生成提示词（中文版，含中文标签）

下面 4 组提示词用于直接生成参赛设计文档中的最终版技术图。整体风格要求保持一致：平面简洁、技术文档风、白色或浅灰背景、圆角卡片、细线连接、适度留白、少装饰、不要玻璃质感、不要 3D、不要霓虹、不要复杂渐变。

> 使用建议：如果生成模型对中文文字不稳定，可以先生成结构图，再用 PPT / Figma / Canva / 脚本把中文标签覆盖上去。但以下提示词已经包含完整中文标签，可直接尝试生成最终版。

## 1. 系统总体架构图

```text
请生成一张 16:9 高清技术架构图，主题是「美团 AI 规划师：本地生活规划与执行 Agent」。

整体风格：
平面矢量技术文档风，白色或极浅灰背景，圆角矩形模块，细线边框，轻微阴影，高级但克制，适合放进参赛设计文档或技术方案 Word 文档。主色使用美团黄色作为点缀，搭配蓝色、绿色、紫色、粉色。不要玻璃质感，不要 3D，不要霓虹，不要复杂渐变，不要科幻发光效果。

版式：
从上到下画 5 个横向分层，每层是一个长条圆角模块，层与层之间用简单向下箭头连接。每层左侧放层级名称，右侧放能力模块。

图片标题：
系统总体架构

副标题：
以用户目标为入口，以可执行任务图为中枢，以长期记忆为增长引擎

第 1 层：
层级名称：体验层
能力模块：自然语言对话、行程确认、协同投票、执行进度、用户档案、AI 回忆录

第 2 层：
层级名称：规划智能层
能力模块：意图与约束抽取、Place Agent、Weather Agent、Strategy Agent、路线与时间分配、方案校验

第 3 层：
层级名称：执行 Agent 层
能力模块：Tool Catalog、依赖图构建、DAG 并行执行、SSE 进度、幂等与补偿

第 4 层：
层级名称：记忆成长层
能力模块：显式偏好、行为追踪、Travel DNA、统一画像、本地 RAG 记忆检索

第 5 层：
层级名称：可靠性与数据层
能力模块：真实 API / Mock 双通道、模型级联、SQLite / JSON 回退、异常分类与自愈

图标建议：
体验层可用对话气泡、日历、用户图标；规划层可用地图针、天气、路线图标；执行层可用齿轮、任务节点、进度条；记忆层可用数据库、档案、DNA 抽象图标；可靠性层可用盾牌、检查、备份图标。

文字要求：
所有中文文字必须清晰、无错别字、不可乱码。使用现代无衬线中文字体效果。文字不要太小，保持适合 Word 文档阅读。
```

## 2. 多 Agent 规划链路图

```text
请生成一张 16:9 高清技术流程图，主题是「规划引擎：约束优先的多 Agent 协同」。

图片标题：
规划引擎：约束优先的多 Agent 协同

副标题：
先理解真实约束，再并行感知环境，最后生成可落地并经校验的完整方案

版式：
从左到右排列流程：
左侧 1 个输入卡片，中间左侧上下并列 2 个 Agent 卡片，中间右侧 1 个 Strategy Agent 卡片，右侧 1 个验证输出卡片，底部 1 个创新点说明框。

标题：目标与约束

人群 / 时间 / 预算

同行偏好与避雷

中间上方卡片：
标题：Place Agent

真实 POI 候选
餐厅、活动与地点

中间下方卡片：
标题：Weather Agent
内容：
天气与环境信号
影响室内外安排

中间右侧卡片：
标题：Strategy Agent

动态时间分配

右侧输出卡片：
标题：验证与版本

输出可确认方案

底部创新点说明框：

箭头关系：
「目标与约束」分别连接到「Place Agent」和「Weather Agent」；
「Place Agent」和「Weather Agent」共同连接到「Strategy Agent」；
「Strategy Agent」连接到「验证与版本」。

图标建议：
目标与约束用靶心图标；Place Agent 用地图针图标；Weather Agent 用云朵太阳图标；Strategy Agent 用路线或棋盘策略图标；验证与版本用检查清单图标。

文字要求：
所有中文文字必须清晰、无错别字、不可乱码。使用现代无衬线中文字体效果。文字不要太小，保持适合 Word 文档阅读。
```

## 3. 执行 Agent DAG 图

```text
请生成一张 16:9 高清技术流程图，主题是「执行 Agent：把方案编译成可执行任务图」。

整体风格：
平面矢量技术文档风，白色或极浅灰背景，圆角节点卡片，细线有向箭头，结构清晰，适合技术设计文档展示。主色使用蓝色，辅助色使用美团黄、绿色、紫色。不要玻璃质感，不要 3D，不要霓虹，不要复杂渐变。

图片标题：
执行 Agent：把方案编译成可执行任务图

副标题：
识别工具依赖关系，同层并行执行，持续回传状态并保留已成功结果

版式：
画一个从左到右的 DAG 有向任务图：
最左侧 1 个起始节点；
中间左侧上下并列 2 个预检查节点；
中间右侧上下并列 2 个执行节点；
最右侧 1 个统一结果节点；
底部放 3 个能力标签。

最左侧节点：
标题：路线计算
工具名：calculate_route

中间左上节点：
标题：餐厅可用性
工具名：check_availability

中间左下节点：
标题：活动余票
工具名：book_activity precheck

中间右上节点：
标题：预约餐厅
工具名：make_reservation

中间右下节点：
标题：预订活动
工具名：book_activity

最右侧节点：
标题：订单与确认
工具名：统一结果 + SSE

底部能力标签：
标签 1：同层 Promise.all 并行
标签 2：幂等重试与补偿
标签 3：部分成功可保留

箭头关系：
路线计算分叉连接到餐厅可用性和活动余票；
餐厅可用性连接到预约餐厅；
活动余票连接到预订活动；
预约餐厅和预订活动共同连接到订单与确认。

图标建议：
路线计算用路线图标；餐厅可用性用餐厅图标；活动余票用票券图标；预约餐厅用日历检查图标；预订活动用活动卡片图标；订单与确认用订单或对勾图标。

文字要求：
所有中文文字必须清晰、无错别字、不可乱码。英文工具名也必须拼写准确。使用现代无衬线字体效果。文字不要太小，保持适合 Word 文档阅读。
```

## 4. 长期记忆飞轮图

```text
请生成一张 16:9 高清技术流程图，主题是「长期记忆飞轮：每完成一次任务，下一次就更懂用户」。

整体风格：
平面矢量技术文档风，白色或极浅灰背景，圆角卡片，细线箭头，结构清晰，温暖但专业。主色使用紫色和蓝色，辅助色使用美团黄、绿色、粉色。不要玻璃质感，不要 3D，不要霓虹，不要复杂渐变，不要过度装饰。

图片标题：
长期记忆飞轮：每完成一次任务，下一次就更懂用户

副标题：
显式档案与隐式行为共同进入统一画像，既提升规划准确度，也创造用户长期资产

版式：
左侧竖排 3 个输入来源卡片；
中间 1 个较大的 Travel DNA 卡片；
右侧中部上下排列 2 个卡片，分别是统一用户画像和记忆索引 / RAG；
最右侧 1 个下一次规划卡片；
底部画一条从「下一次规划」回到「任务完成结果」的闭环箭头。

左侧第 1 个卡片：
标题：显式用户档案
内容：饮食、预算、出行偏好

左侧第 2 个卡片：
标题：行为事件
内容：选择、跳过、投票、搜索

左侧第 3 个卡片：
标题：任务完成结果
内容：预订、完成、打卡、反馈

中间核心卡片：
标题：Travel DNA
内容：
活动类型
预算与时间
协作方式
风格标签

右侧上方卡片：
标题：统一用户画像
内容：
多维偏好 + 行为洞察
显式偏好优先

右侧下方卡片：
标题：记忆索引 / RAG
内容：
历史计划、完成活动
Copilot 对话与档案

最右侧卡片：
标题：下一次规划
内容：
候选排序
提示词上下文
协作策略

底部闭环箭头标签：
新的完成结果再次进入学习循环

可选小模块：
在「记忆索引 / RAG」附近加一个小的故事卡片图标，标注：AI 回忆录

箭头关系：
显式用户档案、行为事件、任务完成结果共同指向 Travel DNA；
Travel DNA 分别指向统一用户画像和记忆索引 / RAG；
统一用户画像和记忆索引 / RAG 共同指向下一次规划；
下一次规划通过底部闭环箭头回到任务完成结果。

图标建议：
显式用户档案用用户头像图标；行为事件用点击或轨迹图标；任务完成结果用对勾或打卡图标；Travel DNA 用抽象 DNA 或指纹图标；统一用户画像用用户卡片图标；记忆索引 / RAG 用数据库或档案盒图标；下一次规划用路线或日历图标；AI 回忆录用书本或故事卡片图标。

文字要求：
所有中文文字必须清晰、无错别字、不可乱码。使用现代无衬线中文字体效果。文字不要太小，保持适合 Word 文档阅读。
```
